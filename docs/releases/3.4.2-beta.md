# PeerCraft 3.4.2 — Beta

Changes since 2.1.0:

- Added in-game settings that persist between launches, including internet play, player limits, mod synchronization and host handoff.
- Redesigned PeerCraft screens with a consistent minimal steampunk theme. Improved connection, account, friends and mod synchronization screens, text wrapping and dialog sizing.
- Added experimental host handoff: the host can offer another player ownership of the running session, transfer the world and let players reconnect. Includes successor selection, confirmation, progress screens and world return.
- Added archive verification, preservation of world-local mod data, interrupted-operation recovery and warnings when opening a stale world copy during handoff.
- Improved player progress preservation when moving to a PeerCraft account UUID, including inventory, ender chest, XP, statistics, advancements and pet ownership. Migration uses backups and conflict checks.
- Added explicit host-approved migration of old guest progress on a closed world. Progress is never assigned automatically by nickname.
- Signing into an account is now required to join through PeerCraft, including room codes and public games.
- Added password login using the full account ID and local recovery cards for recovering a lost friend code. These cards do not reset forgotten passwords.
- Added independent mod synchronization modes for hosting and joining: Off, Required mods only, or All mods. Improved optional client-side mod classification.
- Added exact public-catalog match information and host trust notices to mod synchronization. A catalog listing is not a malware scan or safety guarantee.
- Improved waiting for hosts that take longer to prepare their mod list.
- Fixed immediate reconnect after cancelling a connection attempt and interference from late callbacks.
- Fixed conflicting concurrent friends and public game list requests.
- Fixed room registration when the host's UDP port changes, preserving a single current room.
- Changed the default rendezvous endpoint to connection.peercraft.ru while preserving custom server addresses.
- Added an experimental Fabric 1.16.5 backport.
- Ported the main changes across modern builds and experimental Forge 1.12.2 and 1.7.10 backports.

Host handoff remains experimental. Back up your world before upgrading or testing handoff. Relay/TURN remains disabled; connections still depend on direct P2P connectivity. Email password recovery is not included as a ready-to-use feature.

# Steampunk interface port status

Working status, 2026-10-01. The requested outcome remains the complete approved interface on every supported PeerCraft version/loader.

## Current implementation

- Minecraft 1.21.1–1.21.11 and 26.1–26.2: shared charcoal/brass controls, dialog backgrounds, account identity face tiles, multiplayer tabs, settings and themed transfer/mod-sync dialogs. The 26.x extractor backend now emits the themed background overrides rather than inheriting vanilla backgrounds.
- Minecraft 1.16.5: themed buttons, framed edit fields, responsive dialogs for joining by code, registration, login, rename, account and incoming friend requests. Licensed accounts omit recovery ID. Account skin callback only updates the texture; it does not open another screen. Incoming requests fill available panel height and scroll rather than truncating at eight entries. Join-by-code uses the server configured in Settings. Handoff picker/offer/waiting/reclaim/stale-world dialogs, target/overwrite confirmations, progress notice and all mod-sync dialogs now use themed panels. Long body text and installed mod lists scroll above stacked actions; the mod-selection list uses adaptive rows, themed checkboxes and hover details. In-world dialog backgrounds preserve the visible world and omit particles. Settings now use a central panel with preserved edits on resize, scrollable rows, draggable scrollbar and full label tooltips. LAN-opening retains the original vanilla state/callback owners while drawing a compact brass panel over the visible world; its real input bounds follow the new layout. Multiplayer now has a framed central panel, aligned tab inputs, full-height scrolling Friends/Discover/Games lists and decorated vanilla footer actions. Favorites disables both legacy list background and top/bottom edge rendering; a 1.16.5 list Mixin constrains row/scrollbar geometry to the panel. Refresh opens the same PeerCraft screen/tab, and resized inputs preserve typed values.
- Minecraft 1.12.2 and 1.7.10: themed buttons now support primary actions, and edit/password fields use the shared brass frame. Join-by-code now uses the centered responsive panel, preserves typed code on resize, supports Enter/Back, and uses the Settings server without a redundant override field. Registration, login-by-code/account-ID and rename now use the same responsive panel, full-width primary actions, wrapped statuses and aligned labels. Form values/passwords and pending-action state survive resize; Tab switches fields and Escape returns to the parent. Registration success puts the code, wrapped hint and themed actions inside the panel. Incoming friend requests now fill a centered panel above the Back/status footer, with wheel/Page Up/Page Down scrolling, a draggable brass scrollbar and aligned Accept/Decline actions. Truncated names have full hover text. Resize does not issue duplicate list requests; pending responses disable both actions for that account. Account now uses the identity card and face/hat tiles (64x64 skin on 1.12.2, 64x32 on 1.7.10). Licensed accounts omit recovery ID; nested account parents unwrap to the original screen and asynchronous skin completion only replaces the texture. Logout uses a themed once-only confirmation. Progress notice uses a themed panel and scrollable body above its action. Handoff offer/status/migration, reclaim/overwrite/stale-world and copy-target confirmations now use shared panels, stacked actions and scrollable explanations. The picker places its introduction and scrolling candidate rows above a fixed Cancel action, with full-label hover text and the existing confirmation gate. The shared in-world background keeps the world visible outside the panel and omits particles. All five legacy mod-sync screens now use shared panels and stacked actions. Installed-mod lists and long notices scroll instead of truncating; selection has panel-relative filter/warning/list/footer geometry, full-height two-line rows, themed checkboxes and full-detail hover text, preserving filter/deselection state on resize. Legacy Settings now provide all 20 rows from the 1.16.5 editor, including editable addresses/ports and numeric fields instead of preset-only controls. Panel-relative columns, preserved edits on resize, fixed Save/Reset/Cancel footer, scroll/drag, label tooltips, Tab navigation and focus/reveal of invalid numbers are implemented. Launch-forced controls remain disabled. LAN opening now uses PeerCraftLanScreen, a compact panel over the visible world without particles. Native game-mode/command/publish handlers retain their state and actual hitboxes follow the layout; PeerCraft toggles, max players, public world-name input and stacked Start/Cancel actions use brass controls. Internet-gated fields hide with the internet toggle, and typed world name survives resize. Pause-menu and native GuiOpen entry points select the themed screen. Legacy multiplayer now aligns Friends/Discover/Games input rows to shared content bounds, preserves input on resize and fills the available list height above the footer. Friends and Games gained bounded wheel scrolling; Discover no longer caps results at six rows. Friend captions use two lines, with constrained names/statuses to leave action buttons clear. The multiplayer tabs now share the centered panel and particle background; native footer controls are painted in brass in place, preserving their original callbacks and enabled state. The vanilla fixed heading is suppressed while the panel owns the title. Favorites now has narrowly scoped GuiSlot/ServerSelectionList client hooks: container and overlay backgrounds are canceled, edge-fade batches are flushed under a zero-area scissor, server rows are clipped inside the panel with prior scissor restored, row width/scrollbar align to the panel, and the scrollbar is painted brass with native thumb geometry. Native list input and server entry rendering remain in place. Runtime Mixin application and combined panel/list/header interactions remain unverified.

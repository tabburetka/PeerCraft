Как читать данные. Посетитель — уникальный сетевой адрес; несколько людей за одним роутером считаются одним, а один человек с разными адресами может считаться несколько раз. Аккаунты учитываются только при подтверждённой сессии. Подбор означает ответ сервера с адресами игроков, а не доказанное успешное подключение к миру. Повторные сетевые попытки могут увеличить число подборов. Исторические данные до установки этой версии недоступны.

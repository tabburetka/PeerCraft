# Проверка первого запуска телеметрии

Из `peercraft`:

```sh
./gradlew :1.21.1-fabric:runClient -I ../local-test/telemetry-smoke/init.gradle --offline --max-workers=2
```

Отдельная папка игры: `/tmp/peercraft-telemetry-ui-runtime`. Для повторного сценария
нужен новый/пустой файл настроек PeerCraft только в этой тестовой папке.
Не направлять сценарий на пользовательский инстанс: он меняет выбор в своих тестовых настройках.
Миры не открываются; аккаунтный клиент выключен при старте, диагностика направлена на localhost:9.

Сценарий проверяет настоящий экран и callbacks: запрет до ответа, Escape, сохранение отказа,
кнопку разрешения, отключение одним нажатием без Save и сохранение выбора при reset.
Снимок: `screenshots/telemetry-notice.png` внутри тестовой папки; журнал содержит
`TELEMETRY_UI_COMPLETE`. При ошибке пишет `TELEMETRY_UI_FAILED`. Сценарий сам закрывает игру.
Это проверка интерфейса; успешную игру из внешних сетей она не доказывает.
